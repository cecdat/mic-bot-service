# 搜索任务交叉执行 ASCII 流程图

## 整体执行流程

```
开始执行任务
    │
    ▼
┌─────────────────────────────────────┐
│ 检查配置是否启用交叉执行              │
└─────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────┐
│ 检查账户数量是否 >= 2                │
└─────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────┐
│ 预检查所有账户登录状态                │
└─────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────┐
│ 检查有效登录账户数量是否 >= 2          │
└─────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────┐
│ 启用交叉执行模式                     │
└─────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────┐
│ 执行交叉搜索任务                     │
└─────────────────────────────────────┘
    │
    ▼
结束
```

## 场景对比

### 场景1：交叉执行模式（3个账户，2个已登录）

```
预检查结果：
├── 账户A：已登录 ✅
├── 账户B：已登录 ✅
└── 账户C：未登录 ❌

执行模式：交叉执行

执行过程：
第1轮桌面端：
├── 账户A：跳过登录 → 执行搜索任务
├── 账户B：跳过登录 → 执行搜索任务
└── 账户C：执行登录 → 执行搜索任务

第1轮移动端：
├── 账户A：跳过登录 → 执行搜索任务
├── 账户B：跳过登录 → 执行搜索任务
└── 账户C：执行登录 → 执行搜索任务

优势：
├── 已登录账户快速执行
├── 未登录账户正常登录
└── 整体执行效率高
```

### 场景2：顺序执行模式（3个账户，只有1个已登录）

```
预检查结果：
├── 账户A：已登录 ✅
├── 账户B：未登录 ❌
└── 账户C：未登录 ❌

执行模式：顺序执行

执行过程：
├── 账户A：跳过登录 → 执行所有任务
├── 账户B：执行登录 → 执行所有任务
└── 账户C：执行登录 → 执行所有任务

原因：
└── 有效登录账户 < 2，不适合交叉执行
```

### 场景3：顺序执行模式（1个账户）

```
预检查结果：
└── 账户A：已登录 ✅

执行模式：顺序执行

执行过程：
└── 账户A：跳过登录 → 执行所有任务

原因：
└── 账户数量 < 2，不适合交叉执行
```

## 关键决策点

### 决策点1：是否启用交叉执行

```
条件检查：
┌─────────────────────────────────────┐
│ 1. 配置是否启用交叉执行？            │
│ 2. 账户数量是否 >= 2？              │
│ 3. 有效登录账户数量是否 >= 2？       │
└─────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────┐
│ 所有条件满足 → 启用交叉执行模式       │
│ 任一条件不满足 → 使用顺序执行模式     │
└─────────────────────────────────────┘
```

### 决策点2：单个账户登录状态

```
登录状态检查：
┌─────────────────────────────────────┐
│ 1. 访问 Microsoft Rewards 页面      │
│ 2. 检查多种登录指示器               │
│ 3. 判断是否已登录                  │
└─────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────┐
│ 已登录 → 跳过登录步骤，直接执行搜索任务│
│ 未登录 → 执行完整登录流程，然后执行搜索任务│
└─────────────────────────────────────┘
```

## 错误处理和重试机制

### 任务失败处理

```
单个账户任务失败：
├── 记录失败原因
├── 继续执行下一个账户
└── 在轮次结束后重试失败任务

轮次失败处理：
├── 检查是否有失败任务
├── 如有失败，继续下一轮
└── 达到最大轮数限制时停止
```

### 登录失败处理

```
登录失败：
├── 记录登录失败原因
├── 标记账户为失败状态
├── 继续执行其他账户
└── 在重试阶段再次尝试登录
```
