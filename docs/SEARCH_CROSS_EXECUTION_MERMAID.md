# 搜索任务交叉执行 Mermaid 流程图

## 整体执行流程

```mermaid
flowchart TD
    A[开始执行任务] --> B{配置是否启用交叉执行?}
    B -->|否| C[使用顺序执行模式]
    B -->|是| D{账户数量 >= 2?}
    D -->|否| C
    D -->|是| E[预检查所有账户登录状态]
    E --> F{有效登录账户 >= 2?}
    F -->|否| C
    F -->|是| G[启用交叉执行模式]
    G --> H[执行交叉搜索任务]
    H --> I[结束]
    C --> I
```

## 预检查阶段详细流程

```mermaid
flowchart TD
    A[开始预检查] --> B[遍历所有账户]
    B --> C[创建浏览器实例]
    C --> D[访问 rewards.bing.com]
    D --> E[检查登录状态指示器]
    E --> F{已登录?}
    F -->|是| G[记录为已登录]
    F -->|否| H[记录为未登录]
    G --> I[关闭浏览器实例]
    H --> I
    I --> J{还有账户?}
    J -->|是| B
    J -->|否| K[统计有效登录账户数量]
    K --> L[判断是否启用交叉执行]
```

## 交叉执行模式详细流程

```mermaid
flowchart TD
    A[启用交叉执行模式] --> B[初始化所有账户积分数据]
    B --> C[第一阶段：桌面端交叉执行]
    C --> D[开始第1轮桌面端交叉执行]
    D --> E[遍历所有账户]
    E --> F[账户A：执行桌面端任务]
    F --> G[账户B：执行桌面端任务]
    G --> H[账户C：执行桌面端任务]
    H --> I{有失败任务?}
    I -->|是| J[继续下一轮]
    I -->|否| K[桌面端交叉执行完成]
    J --> D
    K --> L[第二阶段：移动端交叉执行]
    L --> M[开始第1轮移动端交叉执行]
    M --> N[遍历所有账户]
    N --> O[账户A：执行移动端任务]
    O --> P[账户B：执行移动端任务]
    P --> Q[账户C：执行移动端任务]
    Q --> R{有失败任务?}
    R -->|是| S[继续下一轮]
    R -->|否| T[移动端交叉执行完成]
    S --> M
    T --> U[处理积分统计和上报]
    U --> V[重试失败任务]
    V --> W[交叉执行完成]
```

## 单个账户任务执行流程（包含登录）

```mermaid
flowchart TD
    A[开始执行单个账户任务] --> B[检查账户登录状态]
    B --> C{已登录?}
    C -->|是| D[跳过登录步骤]
    C -->|否| E[执行登录流程]
    D --> F[直接执行搜索任务]
    E --> G[访问登录页面]
    G --> H[输入用户名和密码]
    H --> I{需要2FA验证?}
    I -->|是| J[处理2FA验证]
    I -->|否| K{需要辅助邮箱验证?}
    J --> K
    K -->|是| L[处理辅助邮箱验证]
    K -->|否| M[等待登录完成]
    L --> M
    M --> N{登录成功?}
    N -->|是| F
    N -->|否| O[记录登录失败]
    F --> P[任务完成]
    O --> P
```

## 场景示例：3个账户，2个已登录，1个未登录

```mermaid
flowchart TD
    A[预检查结果] --> B[账户A：已登录 ✅]
    A --> C[账户B：已登录 ✅]
    A --> D[账户C：未登录 ❌]
    B --> E[判断结果：启用交叉执行模式]
    C --> E
    D --> E
    E --> F[第1轮桌面端交叉执行]
    F --> G[账户A：跳过登录 → 执行搜索任务]
    F --> H[账户B：跳过登录 → 执行搜索任务]
    F --> I[账户C：执行登录 → 执行搜索任务]
    G --> J[第1轮移动端交叉执行]
    H --> J
    I --> J
    J --> K[账户A：跳过登录 → 执行搜索任务]
    J --> L[账户B：跳过登录 → 执行搜索任务]
    J --> M[账户C：执行登录 → 执行搜索任务]
    K --> N[交叉执行完成]
    L --> N
    M --> N
```

## 场景示例：3个账户，只有1个已登录

```mermaid
flowchart TD
    A[预检查结果] --> B[账户A：已登录 ✅]
    A --> C[账户B：未登录 ❌]
    A --> D[账户C：未登录 ❌]
    B --> E[判断结果：使用顺序执行模式]
    C --> E
    D --> E
    E --> F[顺序执行：账户A]
    F --> G[账户A：跳过登录 → 执行所有任务]
    G --> H[顺序执行：账户B]
    H --> I[账户B：执行登录 → 执行所有任务]
    I --> J[顺序执行：账户C]
    J --> K[账户C：执行登录 → 执行所有任务]
    K --> L[顺序执行完成]
```

## 错误处理和重试机制

```mermaid
flowchart TD
    A[任务执行] --> B{任务成功?}
    B -->|是| C[记录成功]
    B -->|否| D[记录失败原因]
    C --> E[继续下一个账户]
    D --> E
    E --> F{还有账户?}
    F -->|是| A
    F -->|否| G{有失败任务?}
    G -->|是| H[重试失败任务]
    G -->|否| I[所有任务完成]
    H --> J{达到最大重试次数?}
    J -->|否| A
    J -->|是| K[标记为最终失败]
    K --> I
```
