## 🔄 验证码流程

### 1. Node端流程
1. 遇到需要验证码的登录页面
2. 自动填入辅助邮箱并点击发送
3. 调用Service端API创建验证码请求
4. 循环检查验证码状态（每3秒一次）
5. 显示倒计时日志：`等待验证码输入...300s`
6. 收到验证码后自动填入并继续流程

### 2. Service端流程
1. 接收Node端的验证码请求
2. 在验证码管理页面显示待处理的验证码（包含账户、节点、辅助邮箱、创建时间、过期时间）
3. 管理员输入验证码
4. 将验证码传递给对应的Node端
5. Node端收到验证码后继续执行

## 🎯 使用方法

### 1. 启动服务
```bash
# Service端
cd mic-bot-service
docker-compose up -d

# Node端
cd mic-bot-node
docker-compose up -d
```

### 2. 访问验证码管理页面
1. 打开浏览器访问 `http://localhost:2002`
2. 登录管理界面
3. 点击左侧导航栏的"验证码管理"
4. 查看待处理的验证码列表，包含以下信息：
   - **主账户**: Node端正在执行任务的主账户邮箱
   - **节点名称**: 处理该账户的节点
   - **辅助邮箱**: 用于接收验证码的辅助邮箱
   - **创建时间**: 验证码请求的创建时间
   - **过期时间**: 验证码的过期时间
   - **剩余时间**: 倒计时显示剩余时间

### 3. 测试验证码流程
1. 确保Node端配置了正确的辅助邮箱
2. 触发需要验证码的登录流程
3. 在Service端验证码管理页面查看新的验证码请求
4. 输入验证码并确认Node端能收到

## 🐛 故障排除

### 常见问题
1. **验证码立即过期**: 检查时区设置
2. **验证码输入500错误**: 已修复时区问题，统一使用本地时间
3. **验证码列表500错误**: 已修复缺少BotAccount导入问题
4. **API认证失败**: 确保使用正确的Node token
5. **页面无法访问**: 检查Service端是否正常运行
6. **数据库连接失败**: 检查PostgreSQL容器状态
