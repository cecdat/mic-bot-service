# 移动端积分监控页面使用说明

## 功能概述

移动端积分监控页面是一个免登录的、基于Token认证的积分查看界面，专为移动端设备优化设计。用户可以通过输入节点的访问令牌，快速查看该节点下所有账户的积分情况。

## 访问方式

### 页面地址
```
完整地址: http://your-service-domain:2002/mobile_points
简短地址: http://your-service-domain:2002/m
```

### 特点
- **完全免登录**：无需登录service端管理界面
- **无需Token认证**：直接打开即可查看所有账户积分
- **响应式设计**：完美适配移动端设备
- **实时数据**：显示最新的积分和状态信息
- **简短地址**：便于移动端输入和分享

## 使用步骤

1. **打开页面**
   - 在移动端浏览器中访问页面地址（推荐使用简短地址 `/m`）

2. **查看数据**
   - 页面会自动加载所有账户的积分信息
   - 账户卡片默认处于折叠状态，只显示基本信息
   - 点击卡片头部可展开查看详细信息

3. **节点分组功能**
   - 相同节点的账户会自动分组显示
   - 每个节点组有独立的颜色标识
   - 节点组头部显示账户数量和状态统计

4. **状态徽章标识**
   - 🟡 **未更新**：当天数据尚未更新的账户
   - 🔴 **异常**：账号状态非正常的账户
   - 徽章显示在账户邮箱旁边，便于快速识别

5. **折叠/展开功能**
   - 点击账户卡片头部可展开/折叠详细信息
   - 展开时显示：账号状态、总积分、总价值、今日收益、今日价值、最后更新时间
   - 折叠时只显示：账户邮箱、节点名称、状态徽章

6. **自动刷新**
   - 页面每5分钟自动刷新一次数据
   - 也可手动点击右下角的刷新按钮

## 数据说明

### 显示内容
- **账户邮箱**：账户的登录邮箱
- **节点名称**：账户所属的节点
- **账号状态**：账户的当前状态（正常/异常等）
- **总积分**：账户的累计积分
- **总价值**：积分对应的现金价值（按179.25积分/元计算）
- **今日收益**：今日获得的积分
- **今日价值**：今日收益对应的现金价值
- **最后更新**：数据最后更新的时间

### 状态标识
- 🟢 **正常**：账户运行正常
- 🟡 **需要验证**：账户需要验证
- 🔴 **密码错误**：账户密码错误
- ⚠️ **数据过期**：数据超过24小时未更新

## 技术特性

### 前端技术
- **Bootstrap 5**：响应式UI框架
- **Bootstrap Icons**：图标库
- **原生JavaScript**：轻量级交互

### 后端API
- **接口地址**：`/web_api/mobile/get_points`
- **认证方式**：无需认证
- **数据格式**：JSON
- **响应时间**：实时

### 安全特性
- **公开访问**：无需任何认证即可访问
- **数据展示**：显示所有账户的积分数据
- **无状态设计**：不保存用户会话信息

## 故障排除

### 常见问题

1. **页面无法访问**
   - 检查服务是否正常运行
   - 确认端口2002是否开放

2. **页面加载失败**
   - 检查服务是否正常运行
   - 确认网络连接正常

3. **数据不显示**
   - 确认节点下是否有账户数据
   - 检查账户是否有积分记录

4. **数据过期**
   - 节点可能长时间未运行
   - 需要重新执行任务更新数据

### 调试方法

1. **查看浏览器控制台**
   - 按F12打开开发者工具
   - 查看Network标签页的API请求

2. **检查服务日志**
   ```bash
   docker-compose logs api --tail=50
   ```

3. **测试API接口**
   ```bash
   curl http://localhost:2002/web_api/mobile/get_points
   ```
